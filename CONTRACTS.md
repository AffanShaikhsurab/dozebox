# Contracts for the remaining packages

Step 1 of the contracts-first plan: every remaining package's public surface as types, ports and stub functions whose
bodies throw `not implemented: <pkg> <fn>`. Lanes replace the bodies; a change to another lane's contract is a
request in that lane's notes, applied by the orchestrator in a small PR to `main`.

Lanes and what they own (edit nothing outside it, except your own file in `packages/testkit/src/fakes/`):

| Lane       | Packages               | Owns                                                                                                                                               | Testkit fakes file                        |
| ---------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| control    | C1-C6                  | `packages/control`                                                                                                                                 | `fakes-control.ts`                        |
| agent-core | A1, A3, A4, A5         | `packages/agent/src/{boot,supervisor,idle,watchdog}`, `phase.ts`, the A1 shell (`main,deps,run,loops,env,errors,identity`, `config/`, `adapters/`) | `fakes-agent.ts` (shared with agent-edge) |
| agent-edge | A2, A6, A7, A8, A9     | `packages/agent/src/{protocol,spot,disk,net,records,alerts,logs,jail,update}`                                                                      | `fakes-agent.ts`                          |
| cli        | L1-L4, D1-D3           | `packages/cli`                                                                                                                                     | `fakes-cli.ts`                            |

## Knip ignores added for stubs

None. Every stub module is reachable from a `src/**/index.ts` barrel (knip entries), so unused-export findings do not
apply; lanes may drop a barrel once a real caller imports the module.

## Deviations from the plan (smallest option chosen)

- C1 and A1 have no stub files here: C1's files are on `phase-2/c1`, A1's on main. Stubs that would share a path
  were moved: the plan's `alerts/sink.ts` and `wake/source.ts` are `ports/alertSink.ts` and `ports/wakeSource.ts`
  (covered by the existing `./ports/*` export); the alert-sink `SecretReader` is `ports/sharedSecrets.ts` (C1 owns
  `ports/secrets.ts`); C3 has no `tick.ts` stub (C1's seam is the file C3 fills).
- C2 keeps no separate wake ledger or intent store: C1's `state/desired.ts` already has both. The intent id for
  action tokens is the desired state's fence (`desiredOrder`).
- `SinkLogger` matches C1's `Logger` (`log(level, msg, fields)`) instead of the plan's `info/warn/error`.
- A3 lives in `supervisor/` (lane table) instead of the plan's `payloads/`; A5's park in `idle/park.ts`.
- Plugin registry is `plugins/index.ts` (knip entry) instead of `plugins.ts`.
- P2 has no `call()` stub (internal; would be an unused export).
- The plan's `AlertSinkFactory` is `AlertSinkMaker`: `check-words` forbids the word in `packages/`.
