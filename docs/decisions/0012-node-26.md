# 0012. Node 26 for the agent and the control function

Status: accepted (2026-11-25).

## Context

Tests run TypeScript directly with Node's type stripping, and the Lambda runtime must match what tests run.

## Decision

Node 26 on the box (pinned, for the agent only) and in Lambda (`nodejs26.x`). Packages declare `engines.node >= 24.12`, where type stripping is stable.

## Alternatives

A build step for every test run; an older Node without stable type stripping.

## Consequences

Sources use only erasable TypeScript syntax (no enums, no parameter properties, no value namespaces).
