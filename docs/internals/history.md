# History of legacy/

`legacy/` held the old cloud runner with its history, moved here on 2026-11-25 (phase 0, R1) from the application
repository it grew up in. It was removed before the public release; the scrub drops it from every commit. The import
ran `scripts/history/import.sh` in a scratch clone on a build machine:

- `git filter-repo` kept only `infra/runner/`, `infra/terraform/`, `infra/fis/` and
  `docs/operations/cloud-machine.md`, renamed under `legacy/`.
- `--replace-text` and `--replace-message` applied `scripts/history/scrub-expressions.txt`, the rule generated by
  `scripts/history/fake-id-rule.sh` (every 12-digit number and every 17-hex-digit instance, volume or snapshot id
  except the made-up ones in `scripts/history/fake-ids.txt` that tests compare), and a private expressions file kept
  outside the repository (names, addresses and ids that must not appear here).
- `--mailmap` mapped every human author to `Maintainer <maintainer@users.noreply.github.com>`.
- `scripts/history/verify.sh` then checked the result: gitleaks over all history with `.gitleaks.toml`, no 12-digit
  numbers or resource ids outside the fakes, no personal e-mail domains, no unmapped identities, and no match for any
  private expression. It printed `verify: clean`.

Source: the old repository's `main` at `deb0344be10b4aa87cc25e89dad44aef67bd3d56`. Result: 562 commits, head
`253168f5434897972966f0b6307a0f4b348febb7`, merged into `main` by the commit "Import the old runner's history into
legacy/ (scrubbed)".
